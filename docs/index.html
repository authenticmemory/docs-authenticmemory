Authentic Memory docs

This manual describes how our technology is designed and built.

Authentic Memory is protecting historical records in a synthetic age. We provide non-profit infrastructure to ensure that humanity’s historical record remains distinguishable from AI-generated content.

  • If you are new to Authentic Memory, check out a demonstration and explanation of how it works.
  • If you would like to verify an Authentic Memory proof record visit verify.authenticmemory.org.
  • If you manage an archival collection and would like to use Authentic Memory anchoring, see this explanation and instructions.
  • If you manage an archival collection and would first like to understand how Authentic Memory works before committing to a collaboration, this technology overview page provides the clearest explanation.
  • Otherwise, this manual provides the most detailed and current technical documentation.
